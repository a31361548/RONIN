# Excel 收入核對與帳目可讀性

匯入 Excel 與匯出／回匯入口已移至記帳頁標題下方，名稱說明資料方向。來源明細以 16px、600 字重、28px 行高呈現，標籤、數值和備註分列，手機可換行。

## 本月帳目核對

原「Excel 月彙總」改為比較 Excel 固定／變動支出合計、網站已匯入 Excel 明細及差額。總額一致只代表加總相同，不代表每筆皆已核實。Excel 月收入及檔案資訊收在「查看 Excel 月收入與來源」，不再次計入網站收支。

## 收入可能重複

Excel 月收支只有整月薪資／其他收入，沒有逐筆入帳日。網站收入的月份、收入分類與金額等於對應月彙總欄位時，顯示核對提示；新增或編輯收入儲存後，若符合條件會立即開啟核對視窗。這不是同日期比對，也不會用整月總收入冒充薪資。

可選擇：

- **確認已包含在 Excel 月收入**：保留網站入帳日與原交易，保存核對註解，收入仍在網站摘要中計算一次，排除這筆再次匯出。不捏造正式 ID、同步版本或已同步狀態。
- **保留為另一筆收入**：保存不同筆的註解，繼續待同步。
- **撤回核對**：清除本地核對標記，重新出現可能重複提示。沒有刪除原收入。

核對註解可編輯；切換選項時自動註解會跟隨處理結果，自訂文字保留。API 使用會員、紀錄版本、changeId、未匯出狀態及最新彙總 hash 檢查。收入內容或月彙總改變，舊核對會要求重新確認；未核對時新匯出會被阻擋。已匯出／已有正式同步版本的紀錄不能透過此處撤回批次，需先核對既有同步結果。

目前以一筆金額等於月薪資／其他收入欄位作為候選，未實作多筆收入合計配對或推測日期。網站本地 `sourceRefs.incomeReview` 保存註記；不修改 Prisma 或 v1 JSON payload，不改寫 Excel。

## 驗證

- 41 項 mock API／計算及正式帳本唯讀檢查全數通過。涵蓋疑似收入、確認／另一筆／撤回、版本或彙總過期、已匯出保護、會員驗證與不重複匯出；正式帳本解析前後 bytes 相同。
- TypeScript、修改範圍 ESLint、最終 Next.js build 通過。使用現有 Prisma 產生檔建置，未啟停服務或安裝依賴。
- 瀏覽器讀取使用者現有資料，確認核對提示、停用匯出、收入比較、註解切換及來源字體；390×844 核對視窗無水平溢出。僅修改未儲存表單並取消，沒有保存核對或帳務、確認匯入或匯出批次；暫時分頁已關閉，原分頁保留。
- 首次 lint 因 ESLint 8 與 flat config 不符失敗，改沿用 `.eslintrc.json` 並設定 `ESLINT_USE_FLAT_CONFIG=false`。初次 mock 發現新增情境遺留測試資料，已補每個情境 reset；TypeScript union narrowing 已以明確 guard 修正。後續檢查全部通過。
- 建置仍有既有 Browserslist、baseline、middleware 與 ExcelJS 間接 rimraf 版本提示，未混入依賴升級。

## 回退

可撤回這次來源字體、頁面排序、月核對及收入核對 UI／API，保留先前現金錢包及歷史匯入。若已有核對註記，須保留其讀取與排除重複匯出的保護，不能直接忽略標記而重新匯出收入。沒有資料模型 migration，也沒有自動清除帳務。
