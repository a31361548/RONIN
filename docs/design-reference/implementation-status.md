# 日隅第一版實作狀態

> 更新日期：2026-07-21
> 對照文件：`product-design.md`、`brand-identity.md`

這份文件記錄設計基準與目前程式實作的差異，作為下一輪功能與視覺迭代的比較基線。

## 已落地

### 首頁工作區

- 預設提供快速新增、今日待辦、今日提醒、未完成事項、月曆、最近筆記與自訂文字區塊。
- 「調整首頁」可開啟編輯模式。
- 每個組件可調整顯示／隱藏、寬度與上下順序。
- 桌面版使用 12 欄限制；手機版自動單欄排列。
- 可重設首頁配置。

目前配置先儲存在瀏覽器 `localStorage`，尚未做跨裝置同步。

### 待辦與提醒

- 新增待辦支援標題、備註、開始／結束時間。
- 支援低、一般、重要三種優先級。
- 支援一次性、每日、每週、每月、自訂週期欄位。
- 支援建立、選取、篩選與共用標籤。
- 支援搜尋標題／備註、狀態篩選與標籤篩選。
- 保留完成、恢復、延後與刪除前二次確認。
- 週期資料已保存至 Todo；目前尚未加入背景排程器與瀏覽器通知推送。

### 筆記

- 支援標題、搜尋標題／內容與共用標籤。
- 使用日隅風格的富文字編輯器，支援粗體、斜體、標題、項目清單、編號清單、引用、復原與重做。
- 支援筆記新增、編輯、檢視與刪除前二次確認。
- 目前尚未加入圖片上傳／貼上圖片與連結工具。

### 月曆

- `/dashboard/calendar` 已有獨立月曆畫面。
- 支援切換前後月份、回到今天與選取日期。
- 顯示目前使用者的待辦與打卡記號，並呈現當日摘要。

### 個人化與共用元件

- 設定頁保留目前頭像、上傳與裁切／縮放流程。
- 移除不必要的預設頭像選擇區塊。
- 標籤管理支援建立、修改與刪除；刪除前會顯示影響數量並要求二次確認。
- Toast 與自訂下拉使用共用日隅元件，不使用原生 `select`。
- 側邊欄保留 hover 展開／移出收合與動畫 icon 導覽。

## 尚待補齊

- 首頁配置改為伺服器保存，讓同一帳號在電腦與手機同步。
- 週期提醒的實際下一次安排生成、逾期狀態與瀏覽器通知。
- 筆記圖片、連結與貼上圖片。
- 手機版專用底部導覽與更細緻的觸控尺寸調整。
- Admin 會員管理頁的完整日隅視覺與功能回歸確認。
- 登入後首次修改初始密碼流程與通知權限引導。
