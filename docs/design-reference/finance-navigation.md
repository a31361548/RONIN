# 日隅｜記帳入口規劃

日期：2026-10-13。狀態：對話中的分頁建議已存檔，尚未實作；本次 `/impeccable document` 沒有修改路由、導覽、API 或帳目。以下路徑是候選，不是現有子頁。

## 目標與範圍

讓每天新增、找帳、查看當月收支有明確預設入口；把低頻報表與 Excel 交換集中在各自頁面。保留方便找到的 Excel 入口、待處理提示與既有資料方向。視覺沿用根目錄 `DESIGN.md`；不重新設計品牌。

## 三個子入口

| 入口 | 候選路徑 | 功能 | 主要使用情境 |
| --- | --- | --- | --- |
| 帳目（預設） | `/dashboard/finance` | 月份、收支摘要、交易清單、搜尋／多選篩選、新增／編輯／複製、常用模板、必要的核對提示 | 每天記帳、找交易 |
| 報表與預算 | `/dashboard/finance/reports` | 分類統計、期間報表、近六個月趨勢、預算進度及設定入口 | 分析花費、管理預算 |
| Excel 帳本 | `/dashboard/finance/excel` | XLSX 歷史匯入、總額比對、JSON 匯出／回匯、批次紀錄、同步衝突與待恢復處理入口 | 更新網站副本、核對正式帳本 |

記帳設定仍為按鈕，管理分類、帳戶、模板及預設值。收入／支出／信用卡／資金異動以帳目頁篩選呈現。來源詳情與收入核對仍可從相關交易直接打開，不強迫跨頁找回同一筆。

## 桌面與手機

- 桌面側欄「記帳」之下可展開三個子入口；收合導覽仍能進入預設帳目頁。使用鍵盤可到達所有子入口。
- 手機底部維持一個「記帳」主入口，在頁面上方切換帳目、報表與預算、Excel 帳本。
- 帳目頁首保留簡潔的 Excel 帳本連結與待處理數量，詳細交換說明收在 Excel 頁；避免多個大卡片把月份與交易推離首屏。
- 切換後顯示清楚目前頁面及資料月份。各頁是否共用月份、是否用 query 保存篩選與返回位置，待實作時確認，不直接寫成現有行為。

## 跨頁提醒與資料真相

- 待核對、待同步、衝突與待恢復應有可點擊數量，帶到對應紀錄／批次，避免只顯示提醒而沒有下一步。
- 新增現金錢包時就說明現有 JSON 契約無法回寫；不將現金變成銀行帳戶。
- 網站已儲存、Excel 歷史已匯入、交換檔已下載、正式結果已回匯是不同狀態，拆頁後仍明確區分。
- 月支出總額比對只比較加總；一致時仍保留逐筆未核實說明。Excel 月收入沒有逐筆日期，不自動產生薪資交易。
- 寫入成功與清單重讀失敗分開呈現；已送出收入有獨立的核對與批次處理路徑，保留不可變批次保護。
- 正式帳本接收工具、逐筆收入來源及部分金流能力仍須依 `docs/finance-sync.md` 的真實完成狀態呈現。

## 實作驗收建議

1. 預設帳目頁可迅速找到新增、月份、收支摘要與交易；空模板與重複提醒不占大量空間。
2. 三個子入口可直接導向、重新整理與返回；桌面／手機／鍵盤均可操作，啟用項正確。
3. 篩選、模板、來源、收入核對、編輯／複製與刪除還原行為保持一致；資料與會員權限不因拆頁改變。
4. Excel 匯入預覽、更新來源、匯出快照、回匯確認及衝突流程延續既有保護，不把頁面切換誤作同步成功。
5. 網站報表的資料範圍與缺資料提示可辨識，不把未有逐筆收入資料的月份誤稱為確認零收入。
6. 狹窄螢幕無水平溢出，重要狀態可讀，觸控區、焦點與文字對比改善有實際驗證。
