# 日隅｜品牌識別基準

> 版本：v1.0
> 更新日期：2026-07-21
> 狀態：第一版 Logo 已建立，後續可依登入頁實際比例微調

## 品牌名稱

正式名稱：**日隅**

讀音：**ㄖˋ ㄩˊ（rì yú）**

品牌概念是「日常裡屬於自己的角落」：使用者可以在這裡整理今天的事情、記下想法，也保留一點自己的空間。

## Logo 概念

Logo 由三個元素組成：

- 圓角方形：代表一個安定、私人的工作區。
- 折角紙張：代表記事、待辦與提醒。
- 珊瑚色主體與鼠尾草綠圓點：延續產品溫暖、安靜的視覺語言，也保留「今天有一個小焦點」的感覺。

## 使用檔案

- `public/image/brand/riyu-mark.svg`：純圖形 Logo，適合 favicon、手機導覽、頭像與小尺寸場景。
- `public/image/brand/riyu-wordmark.svg`：圖形加「日隅／個人記事與提醒」字標，適合登入頁、桌面側欄與品牌介紹。

## 使用規則

- Logo 周圍保留至少一個「紙張圖形高度」的留白。
- 小尺寸使用 `riyu-mark.svg`，不要把完整字標縮到無法閱讀。
- 不拉伸、不旋轉、不加外框、不使用霓虹或全息效果。
- 在複雜背景上使用米白底或加低強度遮罩，確保紙張與文字輪廓清楚。
- 正式登入頁與 Dashboard 實作時，名稱統一使用「日隅」，不要再使用概念圖中的 `mémoria`。

## 後續可延伸

- 暗色版 Logo。
- 單色列印版 Logo。
- 瀏覽器 favicon 與 PWA icon 尺寸輸出。
- 以 Logo 圓點作為完成狀態、今日焦點或通知徽章的輔助圖形。
